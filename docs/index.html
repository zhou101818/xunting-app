使用须知

  • 定时功能只在页面保持打开时生效。建议把本应用添加到手机主屏幕并保持页面在后台。
  • 浏览器限制自动出声：先用播放键手动播过一次之后，定时播放一般就能自动出声；若被拦截，页面会弹出提示，点一下播放即可。
  • 重新打开页面后，若提示需要授权，点击左侧磁带即可恢复（统计与进度不会丢失）。
  • 收听时长按真实时间累计，与倍速无关；数据全部存本机，不上传。
